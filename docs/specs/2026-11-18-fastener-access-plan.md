# Fastener access

Fusion is the behavioural reference. Keep measured behaviour separate from
inferences. The installed interface declares modelled threads, handedness,
length and offset. A printed thread needs geometry, not a display annotation.

Use the existing metric tables through a read-only MCP tool and hole presets
in the viewer. A preset changes hole and head dimensions. It must preserve the
source, depth and placement. The user can edit each dimension after selection.
Do not add a second table to the interface crates.

Use existing helix and sweep features to check a modelled thread. Import a real
downloaded screw unchanged and keep its source and licence with the example.
Do not describe an approximate demonstration thread as a certified fit.

1. Test MCP dimension lookup and refusal of unknown sizes.
2. Test hole presets, retained expressions and unsupported head sizes.
3. Connect the existing tables to MCP and the viewer.
4. Check the modelled thread and downloaded part through MCP.
5. Check exports in an offline slicer. Do not send data to a printer.
