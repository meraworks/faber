# Modelled thread demonstration

This project was built through MCP. A triangular section follows a three-turn
helix and joins a cylindrical shaft into one solid. Radius is 10 mm and pitch
is 5 mm. An intersection trims both ends to flat faces. This prevents the
isolated ridge tip from forming an empty first layer in the slicer. The final
outputs are in `verification-trim`; `verification` retains the initial check.

This is a geometry demonstration, not a purchased screw or a standard thread
fit. Its ridge is real geometry in the STEP and STL outputs. It does not rely
on a texture or display annotation. The downloaded screw is a separate example
in `../fastener-check`.
